## 🧠 What is the Todos Application?

A responsive Todo app that lets users add, complete, and delete tasks — with everything persisted in the browser via `localStorage`, so tasks survive page refreshes and browser restarts. The project is a focused demonstration of core frontend fundamentals: DOM manipulation, event-driven programming, and dynamic UI updates, all without a single external framework driving the logic.

---

## ✨ Key Features

| Feature | Description |
|---|---|
| ➕ **Add Tasks Dynamically** | Tasks are created and rendered on the fly, no page reload |
| ✅ **Mark as Completed** | Toggle task state with instant visual feedback |
| 🗑️ **Delete Instantly** | Remove tasks from the list and storage in one action |
| 💾 **Persistent Storage** | All tasks saved to `localStorage`, so nothing is lost on refresh |
| ⚡ **Real-Time UI Updates** | DOM updates directly in response to state changes, no reload |
| 🎯 **Responsive Design** | Clean, mobile-friendly interface built with Bootstrap |

## 🚀 Getting Started

### 1. Clone the repo

```bash
git clone https://github.com/saikumarbulasala/Todos-Application.git
cd Todos-Application
```

### 2. Run locally

No build step required:

```bash
open index.html
```

Or serve it with a simple local server:

```bash
npx serve .
```
